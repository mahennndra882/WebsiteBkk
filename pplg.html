PPLG - Bursa Kerja Khusus

Siap kerja di dunia industri IT dan teknologi

Tentang PPLG BKK

PPLG BKK adalah program yang menghubungkan siswa jurusan Pengembangan Perangkat Lunak dan Gim dengan dunia kerja seperti perusahaan IT, startup, dan industri digital.

Skill yang Dibutuhkan

💻 Web Developer

HTML, CSS, JavaScript, Bootstrap, React dasar

📱 Mobile Developer

Flutter atau Android Studio dasar

🎮 Game Developer

Unity dasar, logika game, C# dasar

Lowongan Kerja PPLG

Junior Web Developer

Perusahaan: Startup Teknologi

Skill: HTML, CSS, JavaScript

IT Support

Perusahaan: Digital Company

Skill: Komputer dasar & jaringan

Penyaluran Kerja

Lulusan PPLG akan disalurkan ke perusahaan mitra seperti startup, software house, dan industri teknologi.
